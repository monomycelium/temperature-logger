# ESP32 Temperature Logger

> **AI Disclosure:** All code and documentation were generated by ChatGPT.

A simple temperature logger using an ESP32-C3, DS18B20 sensor, SSD1306 OLED and TTP223 touch sensor. Temperature readings are sent over Wi-Fi to a lightweight C HTTP server and stored in CSV files.

## Features

- **Deep sleep:** Conserves battery between readings.
- **Periodic logging:** Uploads temperature every 5 minutes.
- **Quick view:** Touch the sensor to display the temperature for 5 seconds.
- **Live mode:** Long-touch (1.5 seconds) to continuously display temperature and enable an HTTP server. Touch again to exit.
- **Profiles:** Store readings from different locations in separate CSV files.
- **CSV downloads:** Retrieve recorded data over HTTP.

## Hardware

ESP32-C3 Super Mini, DS18B20 (with pull-up resistor), SSD1306 I²C OLED, TTP223 touch sensor.

| Component | ESP32 GPIO |
|---|---|
| DS18B20 DATA | GPIO0 |
| OLED SDA / SCL | GPIO1 / GPIO2 |
| TTP223 SIG | GPIO3 |

Power: 5V pin (e.g. 3 × AAA alkaline batteries). Sensors and OLED use 3V3.

## Setup

### ESP32 firmware (Arduino)

Install `OneWire`, `DallasTemperature`, `Adafruit GFX Library` and `Adafruit SSD1306`.

Create `arduino_secrets.h`:

```cpp
#define SECRET_SSID "your_ssid"
#define SECRET_PASS "your_password"
```

Update `SERVER_URL` in the sketch to point to your server, then compile and upload using Arduino CLI or Arduino IDE.

### C server (tested with Linux)

No external libraries required.

```bash
gcc -std=c11 -O2 -Wall -Wextra server.c -o server
./server
```

The server listens on port `6767` and stores readings in `profiles/<name>.csv`. It can run inside an Incus container.

## HTTP API

**C logging server (port 6767)**

| Endpoint | Purpose |
|---|---|
| `POST /temperature` | Record temperature |
| `GET /temperature` | Latest recorded temperature |
| `GET /temperature.csv` | Download active profile |
| `GET /profiles` | List profiles |
| `POST /profile` | Create/switch profile |

**ESP32 (port 80, live mode only)**

| Endpoint | Purpose |
|---|---|
| `GET /temperature` | Current temperature |
| `GET /status` | Device status |
| `POST /sleep` | Exit live mode |

## Code overview

- **ESP32:** Reads the sensor, handles touch input, manages deep sleep, updates the OLED and communicates over HTTP.
- **C server:** Accepts HTTP requests using POSIX sockets, validates readings and appends timestamped data to CSV files.
